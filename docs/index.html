MACANIKAL

Your keyboard, but it goes thock.

A tiny menu bar app for macOS that plays real mechanical switch recordings as you type — with obsessive, single-digit-millisecond latency.

Every detail tuned for feel

Keyboard sound apps live or die by one thing: does the sound land with the keystroke, or just after it? Macanikal is built around that question.

🎧

13 real switch packs

Recorded from actual boards — Holy Panda, Topre, Buckling Spring, MX classics and more. No synthesis, no imitation.

⚡

Single-digit-ms latency

A listen-only event tap feeds an always-running audio voice pool with a 128-frame hardware buffer (~2.7 ms). Sound starts on the next render cycle.

🎹

Row-accurate samples

Each keyboard row has its own recording. Space thumps, enter clunks, backspace snaps — like a real board.

🔼

Press and release

Real switches make sound both ways. So does Macanikal — with a toggle if you prefer press-only.

🎲

Humanized playback

Subtle random pitch, stereo position, and level on every keystroke, so fast typing never sounds like a machine gun.

🔒

Private by design

Listen-only tap, zero logging, zero network. Key codes become sounds and are immediately forgotten.

The keystroke-to-sound path

Everything that could add milliseconds has been removed — including the 5–20 ms of silent lead-in hiding at the start of most recorded samples, which reads as input lag.

   ▼
